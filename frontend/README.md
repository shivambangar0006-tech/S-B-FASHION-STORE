# S&B Fashion Store — Frontend

This folder contains the customer-facing storefront for the S&B Fashion Store portfolio project.

## Current stage

This frontend stage includes:
- Responsive S&B fashion storefront
- Navigation and category links
- New arrivals and product catalogue
- Category filtering
- Product search
- Add-to-bag interaction
- Wishlist interaction placeholder
- S&B Couples section
- Build Your Look entry point
- Sale section
- About and developer credit
- Mobile responsive layout

## Important

Product data, cart persistence, customer accounts, payments, reviews, location services, AI support, and admin management will be connected in later development stages.
